## 1.1 Concepto y Naturaleza de la Argumentación Jurídica

### ¿Qué es la Argumentación Jurídica?

La **argumentación jurídica** es el proceso mediante el cual un operador del derecho (abogado, juez, fiscal) presenta razones y justificaciones para sostener una posición legal ante un tribunal u otro órgano decisor.

**Características principales:**
- Es **racional**: Basada en razones y lógica
- Es **dialéctica**: Considera argumentos de ambas partes
- Es **normativa**: Aplicable al derecho existente
- Es **persuasiva**: Busca convencer al juzgador
- Es **justificada**: Fundamentada en leyes, jurisprudencia y principios

### Diferencia entre Argumentación y Retórica

| Aspecto | Argumentación | Retórica |
|--------|---------------|----------|
| **Objetivo** | Justificar racionalmente | Persuadir emocionalmente |
| **Base** | Lógica y razones | Emociones y estilo |
| **Método** | Deductivo/inductivo | Persuasivo |
| **Contexto** | Jurídico técnico | Cualquier situación |

**En la litigación oral**: Se combinan ambas (argumentación + retórica) para máxima efectividad.

## 1.2 Lógica y Razonamiento Jurídico

### Silogismo Jurídico

El razonamiento jurídico clásico sigue un patrón silogístico:

```
Premisa Mayor:  Ley general (norma jurídica)
Premisa Menor:  Hecho específico del caso
Conclusión:     Aplicación de la ley al hecho
```

**Ejemplo:**
```
Premisa Mayor:   "Todo homicidio doloso es punible"
Premisa Menor:   "Juan cometió homicidio doloso"
Conclusión:      "Juan debe ser castigado"
```

### Limitaciones del Silogismo Jurídico

1. **La interpretación de la norma** no es automática
2. **Los hechos** deben probarse
3. **Pueden existir excepciones** o causal de exclusión
4. **Múltiples normas** pueden aplicarse

## 1.3 Tipos de Argumentos

### 1.3.1 Argumento Deductivo

**Definición**: Razonamiento que va de lo general a lo particular. Si las premisas son verdaderas, la conclusión es necesariamente verdadera.

**Estructura:**
```
Premisa 1: Todos los X tienen la característica Y
Premisa 2: Z es X
Conclusión: Z tiene la característica Y
```

**Ejemplo legal:**
```
Premisa 1: Toda persona mayor de 18 años puede votar
Premisa 2: María tiene 25 años
Conclusión: María puede votar
```

### 1.3.2 Argumento Inductivo

**Definición**: Razonamiento que va de casos particulares a una conclusión general. La conclusión es probable, no necesaria.

**Estructura:**
```
Caso 1: Situación X causó resultado Y
Caso 2: Situación X causó resultado Y
Caso 3: Situación X causó resultado Y
Conclusión: Situación X siempre/generalmente causa resultado Y
```

**Ejemplo legal:**
```
Caso 1: Sentencia A reconoce derecho X en circunstancia Z
Caso 2: Sentencia B reconoce derecho X en circunstancia Z
Caso 3: Sentencia C reconoce derecho X en circunstancia Z
Conclusión: El tribunal tiende a reconocer derecho X en circunstancia Z
```

### 1.3.3 Argumento Analógico

**Definición**: Argumento que aplica la solución de un caso similar a otro caso nuevo.

**Estructura:**
```
Caso Anterior: Tenía características A, B, C y se resolvió de forma X
Caso Presente: Tiene características similares A, B, C
Conclusión: Debe resolverse de forma X
```

**Ejemplo legal:**
```
Caso Anterior: Autor de homicidio culposo con arma de fuego → 3 años
Caso Presente: Autor de lesiones graves culposas con arma de fuego → ¿?
Argumento: Similar peligrosidad, similar culpa → similar pena
```

### 1.3.4 Argumento por Absurdo (Ad Absurdum)

**Definición**: Demuestra que la posición contraria conduce a conclusiones absurdas o contradictorias.

**Estructura:**
```
Supuesto: Si aceptamos la posición contraria...
Derivación: Se sigue lógicamente que...
Absurdo: Lo cual es absurdo/contradictorio
Conclusión: Por lo tanto, la posición contraria es falsa
```

**Ejemplo legal:**
```
Supuesto: Si consideramos válido el contrato sin firma de ambas partes
Derivación: Entonces cualquier persona podría obligar a otra sin su consentimiento
Absurdo: Lo cual viola el principio de autonomía de la voluntad
Conclusión: El contrato requiere firma de ambas partes
```

### 1.3.5 Argumento de Autoridad

**Definición**: Se sostiene una posición porque es respaldada por una autoridad reconocida.

**Tipos:**
- Jurisprudencia de tribunal superior
- Doctrina de expertos
- Estándares internacionales

**Ejemplo:**
```
"La Corte Suprema ha establecido que..."
"Según la Convención Interamericana de Derechos Humanos..."
```

## 1.4 Estructuras Argumentativas

### 1.4.1 Método IRAC

**IRAC** = Issue, Rule, Application, Conclusion

#### I - Issue (Problema/Pregunta Jurídica)

Identifica la pregunta jurídica específica a resolver.

**Ejemplo:**
"¿Es válido el despido del trabajador sin causa justificada?"

#### R - Rule (Norma Aplicable)

Establece las reglas de derecho pertinentes.

**Ejemplo:**
"Según el Código Laboral art. 245, el despido debe estar justificado en causa legal."

#### A - Application (Aplicación)

Aplica la norma a los hechos del caso.

**Ejemplo:**
"En este caso, el empleador no presentó causa legal para el despido, solo indicó 'decisión empresarial'."

#### C - Conclusion (Conclusión)

Concluye sobre la pregunta original.

**Ejemplo:**
"Por lo tanto, el despido es inválido y debe reinstalarse al trabajador."

### 1.4.2 Método CREAC

**CREAC** = Conclusion, Rule, Explanation, Application, Conclusion (más completo)

**Ventaja sobre IRAC**: Coloca la conclusión primero, facilitando seguimiento del argumento.

## 1.5 Falacias y Errores Argumentativos

### ¿Qué es una Falacia?

Un argumento que **parece válido** pero tiene defectos lógicos. En litigación, reconocer falacias ajenas es crucial.

### Falacias Comunes en Derecho

#### 1. **Ad Hominem** (Ataque a la Persona)

**Definición**: Rechaza un argumento atacando a quien lo presenta, no al argumento.

**Ejemplo INCORRECTO:**
```
"El fiscal dice que hay evidencia, pero es conocido por ser corrupto.
Por lo tanto, su argumento es falso."
```

**Corrección:**
```
"El fiscal afirma X. Sin embargo, la prueba muestra Y que contradice..."
```

#### 2. **Straw Man** (El Hombre de Paja)

**Definición**: Distorsiona el argumento contrario para atacarlo fácilmente.

**Ejemplo INCORRECTO:**
```
"Mi colega dice que debemos proteger a los acusados.
Por lo tanto, quiere que los criminales queden libres."
```

#### 3. **False Dilemma** (Falso Dilema)

**Definición**: Presenta solo dos opciones cuando hay más.

**Ejemplo INCORRECTO:**
```
"O esta persona es culpable o es inocente. No hay punto medio."
(Ignora que puede haber duda razonable)
```

#### 4. **Begging the Question** (Petición de Principio)

**Definición**: Asume como verdadero lo que se pretende demostrar.

**Ejemplo INCORRECTO:**
```
"El contrato es válido porque fue válidamente celebrado."
```

#### 5. **Slippery Slope** (Pendiente Resbaladiza)

**Definición**: Sugiere que una acción conducirá inevitablemente a consecuencias extremas.

**Ejemplo INCORRECTO:**
```
"Si aceptamos este precedente, pronto todos los contratos serán nulos."
```

## 1.6 Lenguaje Jurídico y Claridad Argumentativa

### Principios de Claridad Argumentativa

1. **Precisión**: Usa términos técnicos correctamente
2. **Concisión**: Sé breve y directo
3. **Coherencia**: Mantén lógica interna
4. **Univocidad**: Una palabra, un significado

### Errores Comunes de Lenguaje

**❌ Ambigüedad:**
```
"El juez ordenó al policía que detuviera al sospechoso."
(¿Quién detiene a quién?)
```

**✅ Claridad:**
```
"El juez ordenó al policía que detuviera al sospechoso."
(Si necesario, reordenar o usar nombres propios)
```
